## Auth

Auth migrated from `localStorage` Bearer tokens to httpOnly cookies on 2026-02-06.
Frontend `apiClient` uses `withCredentials: true`; backend issues access + refresh
tokens as httpOnly + secure + samesite=lax cookies. Anything reading the access
token from JS (e.g. `document.cookie`, `localStorage.getItem('token')`) is a
regression.

## Multi-tenancy gap

**Status**: NOT IMPLEMENTED. There is no `Organization` model. `Item` is owned per-user via `owner_id`, not per-tenant.

**Why it matters**: code generated by AI tools may assume tenant filtering exists. Until `Organization` is added, every query that returns user-scoped data must filter by `owner_id`. Cross-user reads are a security bug.

**Audit reference**: `docs/audits/claude-setup-audit-2026-04-25.md` (CRITICAL-1).
